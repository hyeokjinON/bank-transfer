# P8-3a Kubernetes 로 옮기기 (kind) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `bash infra/k8s/up.sh` 한 번으로 kind 클러스터(제어 1 + 워커 2)에 인프라 · 모의 은행 · 게이트웨이 1대 · api 2대 · Envoy Gateway 입구를 띄우고, 스모크(로컬 · CI)를 통과시킨 뒤, 단계 2 ~ 5 의 실험(R1 ~ R3 · B1 · B2 · N0 · N1 · D1 · D2 · D2')으로 배포 · 은행 장애 · 망 정책 · 노드 장애에서의 가용성과 정합성을 숫자로 남긴다. 처리량은 재지 않는다.

**Architecture:** 매니페스트는 Kustomize `infra/k8s/base` + `overlays/{local,ci,experiment-*}`. 이미지는 P8-2 `Dockerfile` 그대로 빌드해 `kind load` (태그 `dev-<짧은 커밋>`), 적용은 `build/k8s/<overlay>/kustomization.yaml` 을 만들어 태그만 덮는다(저장소 파일은 그대로). 입구는 Envoy Gateway v1.9.3 (`GatewayClass` · `Gateway` · `HTTPRoute`, 재시도 없음) — `EnvoyProxy` 로 Envoy Service 를 NodePort 30080 으로 고정하고 kind `extraPortMappings` 가 PC `127.0.0.1:8000` 에 잇는다. 인프라 · 모의 은행 · 클러스터 공용 부품은 제어 노드, api · 게이트웨이는 워커.

**Tech Stack:** kind v0.33.0 · `kindest/node:v1.36.4` · kubectl(로컬 Docker Desktop 동봉 v1.36.1, CI v1.36.4) · Kustomize(kubectl 내장 v5.8.1) · Envoy Gateway v1.9.3 (Gateway API v1.6.1 CRD 동봉) · `mysql:8.4` · `apache/kafka:4.1.0` · `redis:7.4-alpine` · `curlimages/curl:8.23.0` · `grafana/k6:2.3.0` · Spring Boot 4.1.1 Actuator 프로브 그룹 · GitHub Actions(`docker/setup-buildx-action@v4` · `docker/build-push-action@v7`) · Git Bash 스크립트

**Spec:** `docs/superpowers/specs/2026-11-12-p8-3a-k8s-design.md` (커밋 2da5ef4 + §16 계획 단계 수정 — 이 계획과 같은 커밋)

## Global Constraints

- 주석 · 문서 · 커밋 메시지는 한국어. 커밋 형식 `type(p8-3a): 한국어 요약` (`infra` · `feat` · `test` · `ci` · `docs` · `chore`), 끝 줄 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **돈 불변식은 건드리지 않는다**: 접수 때 차감 · 잔고 = 원장 합 · 같은 거래번호 은행 송신 1번 · "안 보냄만 다시 보낸다, 모르면 묻는다". 앱 코드 변경은 **게이트웨이 `application.yml` 의 readiness 그룹 + 테스트 1개**뿐. `Dockerfile` · api 코드는 바꾸지 않는다. 부하 도구는 `load/compose/withdraw.js` 의 결과 경로 한 줄만 매개변수로 바꾼다.
- 입구(Envoy)는 **재시도하지 않는다**: `HTTPRoute` 에 `retry` 필드 금지, `BackendTrafficPolicy` 를 만들지 않는다 (P8-2 nginx `non_idempotent` 금지와 같은 규칙 — 보낸 POST 를 다시 보내지 않는다).
- PC 에 여는 포트는 **`127.0.0.1:8000` 하나** (kind `extraPortMappings`, `listenAddress: 127.0.0.1`). namespace `bank-transfer` 의 Service 는 전부 `ClusterIP`(또는 headless).
- **모든 Pod 에 `enableServiceLinks: false`** (스펙 §5 — Service 환경변수가 `REDIS_PORT` · `BANK_GATEWAY_PORT` · `KAFKA_*` 와 겹친다).
- 배치: mysql · kafka · redis · mock-bank · CoreDNS · Envoy Gateway 컨트롤러 · Envoy 프록시 → 제어 노드 (`nodeSelector: {bank-transfer/role: infra}` + toleration `node-role.kubernetes.io/control-plane:NoSchedule`). api · bank-gateway → 워커 (`nodeSelector: {bank-transfer/role: app}`).
- 비밀은 커밋하지 않는다. Secret `db-credentials` 는 `up.sh` 가 `infra/.env`(없으면 `.env.example`)에서 만든다. ConfigMap 에 비밀번호를 넣지 않는다. CI 는 실행마다 임의 비밀번호 (P8-2 `app-smoke` 와 같은 방식).
- 이미지 태그는 `dev-<짧은 커밋>` (이미지에 들어가는 경로가 수정 중이면 `dev-<커밋>-<시각>`), CI 는 `ci`. `latest` 금지. 앱 컨테이너 `imagePullPolicy: IfNotPresent`.
- 버전은 정확히 (`infra/k8s/versions.env` 한 곳): kind `v0.33.0`, 노드 `kindest/node:v1.36.4@sha256:099e049362a1526b2db71494e1947aae99bd16290d7c895f2b7ea312e3cbfaed`, kubectl `v1.36.4`(CI), Envoy Gateway `v1.9.3`, `curlimages/curl:8.23.0`, `grafana/k6:2.3.0`. 인프라 이미지는 Compose 와 같다 (`mysql:8.4` · `apache/kafka:4.1.0` · `redis:7.4-alpine`).
- 시간 순서: preStop `10s` + 앱 graceful 단계 `20s`(바꾸지 않음) + 여유 < `terminationGracePeriodSeconds: 45`. api 롤링 `maxUnavailable: 0` · `maxSurge: 1`. 게이트웨이 · 모의 은행 `Recreate`.
- 프로브: startup `/actuator/health/liveness` 5s × 24, readiness `/actuator/health/readiness` 5s × 2, liveness `/actuator/health/liveness` 10s × 3 (timeout 3s). api readiness 는 Spring 기본(`readinessState`)만 — DB · Kafka · 게이트웨이를 넣지 않는다. 게이트웨이 readiness = `readinessState,bankConnection`, liveness 는 기본.
- Kafka 파티션 3 · api 당 `concurrency: 3` 은 바꾸지 않는다.
- Compose `app` 프로필과 K8s 를 동시에 띄우지 않는다 (둘 다 `127.0.0.1:8000`).
- 클러스터 DB 에 쓰는 행: 실험 `load-p82-u001 ~ u020` (P8-2 시드 재사용), 스모크 `load-p83a-smoke-<시각>`. Compose 개발 DB 는 건드리지 않는다.
- 건드리지도 스테이징하지도 않는다: `.run/2. API (8080).run.xml`(사용자의 커밋하지 않은 수정), `postman/`, `infra/.env`. `git stash` 금지. 스테이징은 **파일 이름으로** (`git add -A` · `git add .` 금지). 커밋 뒤 `git status --short` 에 `.run/2. API (8080).run.xml` 이 ` M` 으로 남아 있는지 확인.
- 셸 스크립트는 Git Bash(로컬) · bash(CI) 둘 다에서 돈다. `MSYS_NO_PATHCONV=1` 은 `lib.sh` 의 래퍼(`k` · `ka` · `d` · `kindc`)에만 — 전역 export 금지 (curl `-o /dev/null` 이 깨진다, P8-2). 스크립트는 `lib.sh` 를 source 해 **저장소 루트로 cd** 하고 상대 경로만 쓴다 (Windows 의 `kubectl.exe` 는 `/c/...` 경로를 못 읽는다). `*.sh` · `*.yml` · `*.yaml` 은 LF.
- 내려받기(kind 바이너리, 노드 · 인프라 이미지, Envoy Gateway 매니페스트)는 처음 한 번 사람의 허락을 받고 한다 (컨트롤러가 묻는다).
- 테스트 수: 기준 = 이 브랜치 시작 때 `./gradlew build` 의 수. Task 8 에서 +1.

- [ ] **Step 5: `infra/k8s/lib.sh`**

```bash
# infra/k8s/*.sh · load/k8s/*.sh 공통. source 하면 저장소 루트로 cd 한다 — 이후 경로는 모두 상대 경로
# (Windows 의 kubectl.exe 는 Git Bash 의 /c/... 경로를 못 읽고, MSYS_NO_PATHCONV 를 걸면 변환도 안 된다)
ROOT=$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)
cd "$ROOT"
# shellcheck source=versions.env
. infra/k8s/versions.env
CTX="kind-$CLUSTER_NAME"

# MSYS_NO_PATHCONV 는 이 래퍼에만 (P8-2 규칙 — 전역이면 curl -o /dev/null 이 깨진다)
k() { MSYS_NO_PATHCONV=1 kubectl --context "$CTX" -n "$NAMESPACE" "$@"; }
ka() { MSYS_NO_PATHCONV=1 kubectl --context "$CTX" "$@"; }
d() { MSYS_NO_PATHCONV=1 docker "$@"; }
kindc() { MSYS_NO_PATHCONV=1 kind "$@"; }
# 비밀번호는 mysql Pod 가 이미 가진 환경변수로만 (PC 명령행에 나오지 않게 — P8-2 와 같은 방식)
sql() { k exec -i mysql-0 -- sh -c 'MYSQL_PWD="$MYSQL_PASSWORD" exec mysql -u"$MYSQL_USER" "$MYSQL_DATABASE" --default-character-set=utf8mb4 -N'; }
ok() { printf '  \033[32mOK\033[0m %s\n' "$1"; }
fail() { printf '  \033[31mFAIL\033[0m %s\n' "$1" >&2; exit 1; }
port_open() { timeout 1 bash -c "exec 3<>/dev/tcp/127.0.0.1/$1" 2>/dev/null; }
# docker -v 에 넘길 PC 경로 (Git Bash 는 C:/..., Linux 는 그대로)
host_path() { if pwd -W >/dev/null 2>&1; then (cd "$1" && pwd -W); else (cd "$1" && pwd); fi; }

# 이미지 태그: 이미지에 들어가는 경로가 깨끗하면 dev-<짧은 커밋>, 수정 중이면 dev-<커밋>-<시각>.
# 같은 태그로 다시 apply 하면 Pod 스펙이 그대로라 롤링이 일어나지 않는다 (R3) — 수정 중인 코드를 같은 태그로 덮지 않게
image_tag() {
  if [ -n "${IMAGE_TAG:-}" ]; then echo "$IMAGE_TAG"; return; fi
  local sha; sha=$(git rev-parse --short HEAD)
  if [ -n "$(git status --porcelain -- apps modules Dockerfile .dockerignore build.gradle.kts settings.gradle.kts gradle)" ]; then
    echo "dev-$sha-$(date +%s)"
  else
    echo "dev-$sha"
  fi
}
# 지금 배포된 태그: api 는 R1 이 -r<시각> 태그로 바꾼다, 게이트웨이는 up.sh · apply_overlay 의 태그 그대로
api_tag() { k get deploy api -o jsonpath='{.spec.template.spec.containers[0].image}' | sed 's/.*://'; }
deployed_tag() { k get deploy bank-gateway -o jsonpath='{.spec.template.spec.containers[0].image}' | sed 's/.*://'; }

# overlay 를 태그와 함께 적용: build/k8s/<overlay>/kustomization.yaml 이 images 만 덮는다 (저장소 파일은 그대로)
apply_overlay() {   # $1 = overlay (local | ci | experiment-*), $2 = 태그
  local dir="build/k8s/$1"
  [ -d "infra/k8s/overlays/$1" ] || { echo "overlay 없음: $1" >&2; return 1; }
  mkdir -p "$dir"
  cat > "$dir/kustomization.yaml" <<YAML
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
resources:
  - ../../../infra/k8s/overlays/$1
images:
  - {name: bank-transfer/api, newTag: "$2"}
  - {name: bank-transfer/bank-gateway, newTag: "$2"}
  - {name: bank-transfer/mock-bank, newTag: "$2"}
YAML
  ka apply -k "$dir"
}

wait_ready() {
  k rollout status statefulset/mysql --timeout=300s
  k rollout status statefulset/kafka --timeout=300s
  k rollout status deploy/redis --timeout=180s
  k rollout status deploy/mock-bank --timeout=180s
  k rollout status deploy/bank-gateway --timeout=300s
  k rollout status deploy/api --timeout=420s
}

# 제어 노드에 고정하는 패치 (CoreDNS · Envoy Gateway 컨트롤러 — 워커 장애 실험에서 DNS · 입구가 같이 죽지 않게, 스펙 §16)
pin_patch() {
  printf '%s' '{"spec":{"template":{"spec":{"nodeSelector":{"bank-transfer/role":"infra"},"tolerations":[{"key":"node-role.kubernetes.io/control-plane","operator":"Exists","effect":"NoSchedule"}]}}}}'
}

# 허용 목록에 없는 임시 Pod 에서 TCP 연결 시도 (N0). 붙으면 연결에 걸린 초(> 0), 막히면 0.000000
np_probe() {   # $1 = 호스트, $2 = 포트
  k run "np-probe-$RANDOM" --image="$CURL_IMAGE" --restart=Never --rm -i --quiet --command -- \
    sh -c "curl -s -o /dev/null --connect-timeout 3 -m 4 -w '%{time_connect}' telnet://$1:$2 || true" </dev/null 2>/dev/null | tr -d '\r' | tail -1
}
```

```bash
#!/usr/bin/env bash
# P8-3a: kind 클러스터 + Envoy Gateway + 인프라 + 앱 + 입구를 한 번에 (스펙 §10). 다시 불러도 된다 (클러스터가 있으면 그대로 쓰고 apply 만)
# 사용 (Git Bash · Linux): bash infra/k8s/up.sh [local|ci]
#   SKIP_BUILD=1    이미지 빌드를 건너뜀 (CI — 앞 단계가 이미 만들었다). kind load 는 한다
#   IMAGE_TAG=…     태그 직접 지정 (기본: lib.sh image_tag)
#   UP_ONLY=cluster 클러스터 · Envoy Gateway 까지만
# 먼저: Docker Desktop 켜기, Compose app 프로필 내리기 (둘 다 127.0.0.1:8000)
set -euo pipefail
. "$(dirname "$0")/lib.sh"
OVERLAY=${1:-local}
[ -d "infra/k8s/overlays/$OVERLAY" ] || { echo "overlay 없음: $OVERLAY" >&2; exit 1; }

echo "[1/7] 사전 확인"
for t in kind kubectl docker; do command -v "$t" >/dev/null || { echo "$t 가 없다 — SETUP §2-9" >&2; exit 1; }; done
d info >/dev/null 2>&1 || { echo "Docker 가 꺼져 있다" >&2; exit 1; }
EXISTS=false
kindc get clusters 2>/dev/null | grep -qx "$CLUSTER_NAME" && EXISTS=true
if [ "$EXISTS" = false ] && port_open 8000; then
  echo "127.0.0.1:8000 을 이미 쓰고 있다 — Compose app 프로필이면: docker compose -f infra/docker-compose.yml --env-file infra/.env --profile app down" >&2
  exit 1
fi

echo "[2/7] 클러스터 ($CLUSTER_NAME, $KIND_NODE_IMAGE)"
if [ "$EXISTS" = true ]; then
  echo "  있음 — 그대로 쓴다"
else
  kindc create cluster --config infra/k8s/kind.yaml --image "$KIND_NODE_IMAGE" --wait 180s
fi
ka -n kube-system patch deploy coredns --type=strategic -p "$(pin_patch)" >/dev/null
ka -n kube-system rollout status deploy/coredns --timeout=180s

echo "[3/7] Envoy Gateway $ENVOY_GATEWAY_VERSION (Gateway API CRD 포함)"
ka apply --server-side --force-conflicts -f "https://github.com/envoyproxy/gateway/releases/download/$ENVOY_GATEWAY_VERSION/install.yaml" >/dev/null
ka -n envoy-gateway-system patch deploy envoy-gateway --type=strategic -p "$(pin_patch)" >/dev/null
ka -n envoy-gateway-system rollout status deploy/envoy-gateway --timeout=300s
ka apply -f infra/k8s/cluster/
[ "${UP_ONLY:-}" = cluster ] && { echo "클러스터 · Envoy Gateway 까지 (UP_ONLY=cluster)"; exit 0; }

TAG=$(image_tag)
echo "[4/7] 이미지 (태그 $TAG)"
for t in api bank-gateway mock-bank; do
  if [ "${SKIP_BUILD:-0}" != 1 ]; then d build --target "$t" -t "bank-transfer/$t:$TAG" . ; fi
  kindc load docker-image "bank-transfer/$t:$TAG" --name "$CLUSTER_NAME"
done

echo "[5/7] Secret db-credentials (infra/.env — 저장소에 비밀을 커밋하지 않는다)"
ENV_FILE=infra/.env
[ -f "$ENV_FILE" ] || ENV_FILE=infra/.env.example
mkdir -p build/k8s
SECRET_ENV=$(mktemp build/k8s/db-credentials.XXXXXX)
trap 'rm -f "$SECRET_ENV"' EXIT
grep -E '^(MYSQL_DATABASE|MYSQL_USER|MYSQL_PASSWORD|MYSQL_ROOT_PASSWORD)=' "$ENV_FILE" | tr -d '\r' > "$SECRET_ENV"
[ "$(wc -l < "$SECRET_ENV" | tr -d ' ')" = 4 ] || { echo "$ENV_FILE 에 MYSQL_DATABASE · MYSQL_USER · MYSQL_PASSWORD · MYSQL_ROOT_PASSWORD 가 모두 있어야 한다" >&2; exit 1; }
k create secret generic db-credentials --from-env-file="$SECRET_ENV" --dry-run=client -o yaml | ka apply -f - >/dev/null
rm -f "$SECRET_ENV"

echo "[6/7] 매니페스트 (overlays/$OVERLAY)"
apply_overlay "$OVERLAY" "$TAG"

echo "[7/7] 준비 대기"
wait_ready
k wait gateways.gateway.networking.k8s.io/bank-transfer --for=condition=Programmed --timeout=180s
ka -n envoy-gateway-system wait pod -l "gateway.envoyproxy.io/owning-gateway-name=bank-transfer" --for=condition=Ready --timeout=180s
echo "올라왔다 (태그 $TAG) — 확인: bash infra/k8s/smoke.sh · 입구 http://127.0.0.1:8000"
```

```bash
#!/usr/bin/env bash
# P8-3a 스모크 (스펙 §10 · §11). up.sh 뒤 입구(127.0.0.1:8000, Envoy Gateway)로 확인한다:
#   0) 워크로드 전부 준비, Gateway Programmed      1) 1원인증 → 모의 은행 로그의 적요 코드 → VERIFIED
#   2) 충전 → 출금 → COMPLETED                      3) 같은 멱등키로 다시 → 같은 출금 id, 200
#   4) 요청 20번이 api Pod 두 개로 (/actuator/info 의 instance = Pod 이름)
#   5) api 두 Pod 가 서로 다른 워커                  6) 게이트웨이 readiness UP, Service 는 전부 ClusterIP, (CI) PC 에 내부 포트 없음
#   7) 컨테이너 사용자 ≠ root
# 사용 (Git Bash · Linux): bash infra/k8s/smoke.sh
# 클러스터 DB 에는 사용자 load-p83a-smoke-<시각> 의 행만 쓰고 끝에서 지운다.
set -euo pipefail
. "$(dirname "$0")/lib.sh"
json() { { grep -o "\"$1\":\"[^\"]*\"" || true; } | head -1 | cut -d'"' -f4; }
code() { tail -1 <<<"$1"; }
body() { sed '$d' <<<"$1"; }

BASE=http://127.0.0.1:8000
USER_ID="load-p83a-smoke-$(date +%s)"
ACCOUNT=1002123456789

cleanup() {
  sql >/dev/null 2>&1 <<SQL || echo "  (정리 실패 — 사용자 $USER_ID 의 행을 손으로 지운다: load/compose/cleanup.sql 과 같은 순서)" >&2
DELETE o FROM outbox_event o JOIN transfer t ON t.id = o.aggregate_id WHERE t.user_id = '$USER_ID';
DELETE FROM wallet_ledger WHERE user_id = '$USER_ID';
DELETE FROM transfer WHERE user_id = '$USER_ID';
DELETE FROM account_verification WHERE user_id = '$USER_ID';
DELETE FROM wallet WHERE user_id = '$USER_ID';
SQL
}
trap cleanup EXIT

post() {   # $1 = 경로, $2 = JSON 본문(표준입력으로 — 한글이 셸 인자 변환을 거치지 않게), 나머지 = curl 인자
  local path=$1 data=$2; shift 2
  printf '%s' "$data" | curl -s -w '\n%{http_code}' -X POST "$BASE$path" -H 'Content-Type: application/json' -H "X-User-Id: $USER_ID" "$@" --data-binary @-
}

echo "[0/7] 준비"
for dpl in redis mock-bank bank-gateway api; do
  r=$(k get deploy "$dpl" -o jsonpath='{.status.readyReplicas}'); w=$(k get deploy "$dpl" -o jsonpath='{.spec.replicas}')
  [ "${r:-0}" = "$w" ] || fail "$dpl 준비 ${r:-0}/$w — bash infra/k8s/up.sh"
done
for sts in mysql kafka; do
  [ "$(k get statefulset "$sts" -o jsonpath='{.status.readyReplicas}')" = 1 ] || fail "$sts 가 준비되지 않았다"
done
[ "$(k get gateways.gateway.networking.k8s.io bank-transfer -o jsonpath='{.status.conditions[?(@.type=="Programmed")].status}')" = True ] || fail "Gateway 가 Programmed 가 아니다"
[ "$(curl -s -o /dev/null -w '%{http_code}' "$BASE/actuator/health")" = 200 ] || fail "입구 $BASE/actuator/health 가 200 이 아니다"
ok "워크로드 준비, Gateway Programmed, 입구 200"

echo "[1/7] 1원인증"
R=$(post /api/v1/account-verifications "{\"bankCode\":\"090\",\"accountNo\":\"$ACCOUNT\",\"holderName\":\"홍길동\"}")
[ "$(code "$R")" = 201 ] || fail "1원인증 요청 $(code "$R"): $(body "$R")"
VID=$(body "$R" | json id)
VCODE=$(k logs deploy/mock-bank --tail=2000 2>/dev/null | grep -a "$ACCOUNT" | grep -ao "BT[0-9]\{4\}" | tail -1 | cut -c3- || true)
[ -n "$VCODE" ] || fail "모의 은행 로그에서 적요 코드(BT + 4자리)를 찾지 못했다"
R=$(post "/api/v1/account-verifications/$VID/confirm" "{\"code\":\"$VCODE\"}")
[ "$(body "$R" | json status)" = VERIFIED ] || fail "확인 $(code "$R"): $(body "$R")"
ok "1원인증 → VERIFIED"

echo "[2/7] 충전 → 출금 → COMPLETED"
R=$(post /api/v1/wallet/deposits '{"amount":10000}')
[ "$(code "$R")" = 200 ] || fail "충전 $(code "$R"): $(body "$R")"
KEY="smoke-$USER_ID"
TRANSFER="{\"bankCode\":\"090\",\"accountNo\":\"$ACCOUNT\",\"amount\":1000,\"memo\":\"smoke\"}"
R=$(post /api/v1/transfers "$TRANSFER" -H "Idempotency-Key: $KEY")
[ "$(code "$R")" = 202 ] || fail "출금 접수 $(code "$R"): $(body "$R")"
TID=$(body "$R" | json id)
S=
for _ in $(seq 60); do
  S=$(curl -s "$BASE/api/v1/transfers/$TID" -H "X-User-Id: $USER_ID" | json status)
  [ "$S" = COMPLETED ] && break
  sleep 1
done
[ "$S" = COMPLETED ] || fail "60초 안에 COMPLETED 가 아니다 (지금 $S)"
ok "출금 $TID → COMPLETED"

echo "[3/7] 같은 멱등키로 다시"
R=$(post /api/v1/transfers "$TRANSFER" -H "Idempotency-Key: $KEY")
[ "$(code "$R")" = 200 ] || fail "같은 키 재요청 $(code "$R"): $(body "$R")"
[ "$(body "$R" | json id)" = "$TID" ] || fail "다른 출금 id: $(body "$R")"
ok "같은 출금 id, 200"

echo "[4/7] 분배"
PODS=$(k get pods -l app=api -o jsonpath='{range .items[*]}{.metadata.name}{"\n"}{end}' | sort | tr '\n' ' ')
INST=$(for _ in $(seq 20); do curl -s "$BASE/actuator/info" | json instance; done | sort -u | tr '\n' ' ')
[ "$INST" = "$PODS" ] || fail "instance 가 api Pod 두 개가 아니다: [$INST] (Pod: [$PODS])"
ok "instance $INST"

echo "[5/7] 분산 배치"
NODES=$(k get pods -l app=api -o jsonpath='{range .items[*]}{.spec.nodeName}{"\n"}{end}' | sort -u | tr '\n' ' ')
[ "$(wc -w <<<"$NODES" | tr -d ' ')" = 2 ] || fail "api 두 Pod 가 한 노드에 있다: $NODES (ScheduleAnyway 라 생길 수 있다 — kubectl rollout restart deploy/api)"
ok "api 노드 $NODES"

echo "[6/7] 게이트웨이 · 포트"
k exec deploy/bank-gateway -- wget -qO- http://127.0.0.1:8082/actuator/health/readiness | grep -q '"status":"UP"' || fail "게이트웨이 readiness 가 UP 이 아니다"
NOT_CIP=$(k get svc -o jsonpath='{range .items[*]}{.metadata.name}{" "}{.spec.type}{"\n"}{end}' | awk '$2 != "ClusterIP"')
[ -z "$NOT_CIP" ] || fail "ClusterIP 가 아닌 Service: $NOT_CIP"
if [ "${CI:-false}" = true ]; then
  for p in 8080 8082 9090 3306 9092 6379; do port_open "$p" && fail "PC 포트 $p 가 열려 있다"; done
fi
ok "게이트웨이 readiness UP, Service 전부 ClusterIP (PC 포트는 입구 8000 하나)"

echo "[7/7] 비root"
for dpl in mock-bank bank-gateway api; do
  u=$(k exec "deploy/$dpl" -- id -u | tr -d '\r')
  [ "$u" != 0 ] || fail "$dpl 가 root 로 돈다"
done
ok "세 앱 모두 root 아님"

echo "k8s smoke 통과"
```

```bash
# 1초 남짓마다 Pod · 노드 상태를 한 줄씩 남긴다 (load/k8s/run.sh 가 배경으로 띄우고 끝나면 죽인다).
```

```awk
# load/k8s/timeline.sh 의 줄 → 실험 시간 지표 (run.sh 가 부른다). ta = 동작 시각(epoch ms, steady 는 0), node = 대상 워커(없으면 -)
# 출력 key=value. 초는 동작 시각 기준. 해당 없음은 null
$1 == "P" {
  t = $2 + 0
  if (!(t in seen)) { seen[t] = 1; ts[++n] = t }
  if ($3 == "api") {
    if ($6 == "True") apiReady[t]++
    if ($6 == "True" && $5 != node) apiOff[t]++
    if ($5 == node && $6 != "True") apiOnNodeNot[t]++
  }
  if ($3 == "bank-gateway") {
    if ($6 == "True") gwReady[t] = 1
    if (!($4 in r0)) r0[$4] = $7
    r1[$4] = $7
  }
}
$1 == "N" && $3 == node && $4 != "True" && ($2 + 0) >= ta && nodeDown == "" { nodeDown = $2 + 0 }
function sec(x) { return sprintf("%.1f", (x - ta) / 1000) }
END {
  min = ""; lastBad = ""; gwNot = 0; podNot = ""; repl = ""
  for (i = 1; i <= n; i++) {
    t = ts[i]; if (t < ta) continue
    c = apiReady[t] + 0
    if (min == "" || c < min) min = c
    if (c < 2) lastBad = t
    if (!(t in gwReady) && i < n) gwNot += ts[i + 1] - t
    if (podNot == "" && apiOnNodeNot[t] > 0) podNot = t
  }
  rec = ""
  if (lastBad == "") rec = "0.0"
  else for (i = 1; i <= n; i++) if (ts[i] > lastBad && apiReady[ts[i]] + 0 >= 2) { rec = sec(ts[i]); break }
  if (node != "-") for (i = 1; i <= n; i++) if (ts[i] >= ta && apiOff[ts[i]] + 0 >= 2) { repl = sec(ts[i]); break }
  restarts = 0; for (p in r1) restarts += r1[p] - r0[p]
  print "api_ready_min=" (min == "" ? "null" : min)
  print "api_recovered_s=" (rec == "" ? "null" : rec)
  print "gw_not_ready_s=" sprintf("%.1f", gwNot / 1000)
  print "gw_restarts=" restarts
  print "node_notready_s=" (nodeDown == "" ? "null" : sec(nodeDown))
  print "pod_notready_s=" (podNot == "" ? "null" : sec(podNot))
  print "replacement_ready_s=" (repl == "" ? "null" : repl)
}
```
